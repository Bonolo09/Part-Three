# ThriveHub

Small static site with resources and templates for young entrepreneurs.

## Quick start
- PowerShell: `.\serve.ps1`
- CMD: run `serve.bat`
- Python: `python -m http.server 8000` (or `py -m http.server 8000`)
- Node: `npx serve -s -l 8000`
- VS Code: use Live Server extension and click "Go Live"

## Compress images
- Script: `compress-images.ps1` (requires ImageMagick `magick` on PATH)
- Run: `.\compress-images.ps1`

## Files
- `INDEX.html`, `ABOUT.html`, `SERVICES.html`, `RESOURCES.html`, `CONTACT.html` — pages
- `style.css` — styles
- `js/script.js` — UI behaviors
- `images/` — image assets
- `documents/` — downloadable templates
- Helpers: `serve.ps1`, `serve.bat`, `compress-images.ps1`
